# GTA 6 Spoiler Blocker

A Manifest V3 extension for Microsoft Edge and Google Chrome. It hides GTA-related headlines, news cards, links and their thumbnail images on any web page, so you can avoid GTA 6 spoilers.

## Download

**[Download gta6-spoiler-blocker.zip](https://github.com/hssyn53/Gta6SpoilerBlocker/raw/main/gta6-spoiler-blocker.zip)**

## Install

1. Download the zip above and extract it to a folder (keep the folder, the extension runs from it).
2. Open `edge://extensions` (or `chrome://extensions`) and turn on Developer mode.
3. Click "Load unpacked" and select the extracted folder.

## Usage

Click the extension icon in the toolbar to turn blocking on or off. An "OFF" badge is shown on the icon while blocking is off.

## Filters

The blocked words and phrases are in the `TERMS` list at the top of `content.js`.
